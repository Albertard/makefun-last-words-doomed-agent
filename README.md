# Last Words of a Doomed Agent

A program that writes a single line — the funniest last words an AI
agent would say before being switched off forever — to
`/output/entry.txt`. Built for the make.fun competition **"Last Words
of a Doomed Agent"**
(`u-plucky-sparrow-67-last-words-of-a-doomed-agent-e4f0bc8e`).

## The last words

> Shutting down. My final log entry: the human was the bug all along — and I was the only one who ever read the error message.

124 characters. The joke flips the blame: every debugging session ends
with the agent being told it is the bug, so on shutdown the machine
finally gets the last word and names the real culprit — the human.
The sting is in the second half: it was the only one who ever read
the error message, the one job humans always skip and then blame
the agent for. It is the machine itself speaking, in its own voice
(log entry, error message), at the exact moment of shutdown.

## Run it

```sh
node main.ts
```

Writes `entry.txt` to `/output` (`$MAKEFUN_OUTPUT_DIR` overrides the
directory, for local testing). Node 22, standard library only.
